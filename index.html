What is GroupSense?

GroupSense is a mobile application for student group project accountability. It helps teachers and students organize tasks, submit evidence, review contributions, and monitor project progress.

Can I use GroupSense on this website?

This website introduces the application and provides its Android download. Classes, projects, and submissions are managed inside the mobile app.

Is there an iPhone version?

The download on this page is an Android APK. It cannot be installed on an iPhone or iPad.

How do I install the Android APK?

Download the APK on your Android phone, open the downloaded file, and follow the installation prompts. If Android asks, allow your browser or file manager to install this app. Only install an APK you trust; you can turn that permission off afterward. Keep Google Play Protect enabled.

Do I need an internet connection?

Sign-in, loading shared project data, uploading evidence, and receiving updates require an internet connection.
